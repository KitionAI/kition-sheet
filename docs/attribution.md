# Asset attribution

Every non-code asset in this repository (images, icons, fonts, example files, presets) is listed here with its author, source and license. `cargo xtask assets` (part of `cargo xtask ci`) fails if an asset file is missing from this table.

**Policy (mandatory):** This kit contains **no Microsoft, Adobe, Avid or Autodesk iconography, images, artwork, fonts, templates, themes, table styles or sample files**. Every asset is original work by Kition contributors, upstream contributors (see NOTICE) or third-party material under an open license (OSI open source, public domain / CC0, or Creative Commons that allows redistribution). Screenshots of Microsoft software are never committed. Font files are not added here: the faces the web build ships (Droid Sans Fallback, Apache-2.0; Ma Shan Zheng, Carlito, Caladea, Arimo, Tinos and Cousine, OFL-1.1) live in [KitionAI/kition-fonts](https://github.com/KitionAI/kition-fonts), an optional build input (`KITION_FONTS_DIR`) that `web/scripts/build-engine.sh` copies, with each license file, into the kit's web build; the engine also compiles in the epaint_default_fonts faces (Ubuntu Light, Hack, Noto Emoji, emoji-icon-font).

Generated-in-code art is original and has no file to list: themes (`crates/engine/engine/src/cmd/view.rs`), cell styles (`crates/engine/engine/src/cmd/format.rs`), table styles (`crates/engine/engine/src/tables.rs`), chart palettes and the sample workbooks (`crates/engine/engine/src/sample.rs`).
